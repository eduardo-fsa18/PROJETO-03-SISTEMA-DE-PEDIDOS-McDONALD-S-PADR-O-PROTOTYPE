# PROJETO-03-SISTEMA-DE-PEDIDOS-McDONALD-S-PADR-O-PROTOTYPE

Um pequeno projeto em javascript ultilizando o metodo Prototype.

Ele realiza a criação "cardápio" com McOfertas que pode ser clonada e editada para realizar a edição no tamanho da batata e/ou do refrigerante. Esse projeto foi todo desenvolvido em JavaScript ultilizando o PadrãoGof de Criação e o metodo Prototype
